# 第3章 结果

文献中，迁移学习通常被定义为：先前学习对后续新任务或新情境中的学习和表现产生影响，这种影响可以是促进、干扰或接近于零（Thorndike & Woodworth, 1901；Perkins & Salomon, 1992/1994）。在动物研究里，经典描述不是笼统地说“学过一个任务后另一个任务更好”，而是更具体地看旧经验是否让动物在新任务上起点更高、达到标准更快，或学习曲线更陡（Harlow, 1949；Barnett & Ceci, 2002）。经典实验方法主要有三类：第一类是 learning set 范式，让动物连续解决一系列相似辨别问题，观察是否出现“学会如何学习”的加速（Harlow, 1949）；第二类是辨别迁移、反转学习和维度转换，保持部分规则不变、替换关键线索或奖惩关系，观察动物是否能把旧策略迁移到新问题上（Lawrence, 1949；Sutherland & Mackintosh, 1971）；第三类是更接近本文的跨模态或跨线索替换范式，即在反应要求基本不变时，把支配性提示从一种感觉线索换成另一种线索，检验旧任务经验是否节省新线索学习（Wylie, 1917）。空间学习中的平台换位或线索重排，也常被用来测量迁移与认知灵活性（Vorhees & Williams, 2006）。基于这一传统，本文把迁移学习具体限定为：学会A任务后，再学结构相近但提示模态不同的B任务时，动物是否比直接学习B任务更快。本文中，A任务是声水，B任务是光水。

什么是“快”？
- 学习曲线整体抬升：每一个固定时点（特别是 First block）的表现都更好
- 学习曲线陡峭：相邻Block之间的提升更大，从 First block 到 First 100% block 之间经过的block数更少，整体斜率更大

# 为什么会快？
什么是快被拆分成了 First block 更高和斜率/增量更大两个指标，各有不同的原因。
## First block 更高
First block，测试的是对已有记忆的静态读出。它更高的意思，就是迁移Cue无需训练就有一定概率直接激活行为。要理解这种现象，必须先确认A任务的所谓“学会”状态是通过怎样的机制实现的。行为之所以需要Cue来激活，是因为声水任务学会的小鼠，实际上学会了：
1. 给声音时，立即舔水，称动作态
2. 没有声音时，抑制舔水冲动，称静息态

这是两套互相拮抗的网络状态，而Cue就是从静息切换到动作的信号。想要从静息状态快速切换到动作状态，有两种可能（或兼有）的方式：
- Cue信号被特异性迅速级联放大，将静息状态的支配地位瞬间摧毁。（表现：学会后Cue响应（0-1s状态距离）增加）
- 静息状态本身会随时间不断自发向动作状态衰变，Cue信号只是加速了这个衰变过程。（表现：给Cue后舔水前状态变化方向与之前的静息态变化方向大致相同，但速度更快，或者说在同方向上加速而非减速；这个方向还与自发舔水前的变化方向相同）

那么，迁移学习的 First block 更高，就可以约化为迁移Cue能比初始状态下更高概率成功令网络从静息态切换到动作态；对应地，迁移的机制可能发生在Cue信号的级联放大通路上，也可能发生在静息态向动作态自发衰变模式的保留上。而这些效应的强弱也和声水活跃细胞有多少被光信号重激活有关，体现在鼠间差异的相关性和命中错失的差异上。

还存在一个操作性问题：在生物神经网络中，并不存在一个静态的“状态”，一切状态都是通过循环维持的。加上随机的时间设定，这就意味着，Cue信号到来时，网络可能处于静息状态的任何一个相位，处于兴奋/抑制状态的细胞群体并不完全一致。因此，Cue的输入通路必须有自适应性/稳健性的特征，使得以下两种可能成立：
- 无论静息状态处于哪个相位，Cue输入都能迅速将其收敛到少数几种动作状态
- 对每个静息状态的相位，Cue输入都有对应的动作状态

这个问题可以通过验证比较多回合的0s/1s处状态散度来判定。

cFos抑制和等待7天实验均支持上述论断。
## 斜率/增量更大
学习曲线一般不是一条直线，每一段的斜率与该段起点所在的高度相关。此处说迁移学习的斜率更大，是通过线性模型排除了起点高度效应后，仍然残留的斜率更大。也就是说，即使是在行为表现相同水平上，迁移学习仍然预期下一个Block会比初始学习提升更大。这是怎么回事呢？

全局的突触可塑性，在本迁移任务持续最多不超过一个月的时间尺度上，应当可以认为是稳定不变的，也没有理由、证据或任何迹象显示仅仅一个声水预训任务就能显著改变全局的可塑性水平。也就是说，迁移学习的斜率更大，不太可能是因为突触可塑性水平的提升导致的。既然每一步训练的“步长”不变，那唯一的可能，就是每一步训练的“方向”更对了。也就是说，迁移学习的斜率更大，是因为每次训练都更有效地沿着正确的方向调整了网络状态。

虽然本实验没有直接对突触强度进行测量，但由于学习方向实际上是由活跃状态决定的，所以研究活跃状态的变化就可以间接研究学习方向的变化。由于兴奋抑制平衡效应，一个“正确”的学习方向，一定是会给每个细胞分配一个“兴奋”或是“抑制”的角色。那么，要朝着正确的方向前进，兴奋的细胞就应该越来越兴奋，抑制的细胞就应该越来越抑制。这个过程越顺畅，学习就应该越快；相反，如果有大量细胞角色不明朗，时而兴奋时而抑制，学习方向也就不明确，就会缓慢。进一步，由于钙信号对兴奋/抑制呈积累效应，角色明朗的细胞亮度会稳定增长或衰退，而角色不明的细胞亮度则会在0附近震荡。因此，可以用细胞间标准差，或称响应异质性，衡量学习方向的明确稳定一致性。注意这里不可以用回合间标准差计算，因为它忽略了一个回合内部随时间的钙信号积累方向是否稳定。较大的响应异质性意味着每个细胞具有更明确的角色，将网络朝着明确的方向训练，因而学习效率较高。

实测证据支持响应异质性与学习速度的关联。但2/3层和5层分工不同：2/3层主要反映鼠间先天差异，5层反映初始/迁移差异，即响应异质性的迁移性主要体现在5层。MOp5层和TH脑区有较强关联，抑制TH发现5层的响应异质性下降，学习速度也随之下降，2/3层则影响不显著，说明这种响应异质性依赖TH的支持。
## RSP的上游转发
从皮层拓扑上看，RSP是视觉和运动的一个直接中继脑区。实测发现RSP的确对视觉信号响应远强于听觉。RSP本身活动强弱对命中/错失不敏感，但仍与声水活跃细胞的重激活有关。RSP的静息态远比MOp平稳，但其切换到动作态的速度也比MOp快。这说明MOp的静息态可能更多靠其它脑区维持，而RSP起到转发视觉信号、促进动作态切换的上游功能。
