# 文稿待补充与重点审核清单

## 1. 需要你手动补充或核实的实验细节

### 1.1 样本量与纳入排除
- 每一类实验的最终纳入鼠数需要逐图、逐面板明确补上，包括：基础行为、基础成像、cFos 抑制、MOp 非特异性抑制、TH 抑制、Vacation7、RSPd、RSPd+MOp、mCherry 对照。
- 需要补清楚哪些鼠因为什么原因被排除：颅窗质量、配准失败、Transfer LightWater 非纯会话、Naive 阶段混入 AudioWater、会话缺失、病毒表达失败、操纵后状态异常等。
- 需要明确正文中“只有一部分鼠的颅窗符合拍摄要求”对应的实际数量和比例。

### 1.2 行为流程与参数
- 需要确认 30 个重复回合是否是单会话固定值，还是首会话训练模板，后续会话回合数是否完全相同。
- 需要确认 20 s 固定间隔是否在所有批次、所有操纵实验中保持一致。
- 需要明确“达到 100% 命中后结束初始/迁移阶段”这一规则在实际数据库中是否有例外，例如达到 100% 后是否仍拍了额外巩固会话。
- 需要补一个更正式的行为时序示意图说明，尤其是 0 s、1 s、1.5 s 分别对应什么事件。

### 1.3 手术与病毒
- 建议补全 GCaMP6f、hM4D(Gi)、mCherry、DIO-hM4D(Gi) 等病毒的滴度、货号或内部批次信息。
- 需要核实 MOp、PO、RSPd 注射坐标的写法是否全部统一为同一参照系，避免部分用 Interaural、部分用 Bregma 而未注明。
- cFos-CreER 与 tamoxifen 的标记时间窗、注射次数、具体日程需要在方法中更清晰地标准化描述。

## 2. 需要你重点审核、可能猜想成分较大的内容

### 2.1 关于机制拆分的表述
- “迁移优势由起点优势与增长优势两个组件构成”是本文最核心的组织逻辑，但目前仍主要基于现有分析口径的整合解释，不是单个实验直接证明的事实。建议你重点审核是否愿意把它上升为全文主论点。
- “MOp2/3 更偏调用，MOp5 更偏反馈更新”是依据层间统计差异与操纵方向提出的工作模型，合理但仍带推断色彩。
- “迁移学习拥有一个更好的老师”是便于行文的比喻性表达，建议根据送审风格决定是否保留，或改写为“反馈训练信号更接近最终正确结构”。

### 2.2 关于 TH/PO 与反馈通路
- 文稿中将 TH 主要解释为反馈训练信号上游，尤其强调 PO 与 MOp5 的关联，这一解释与数据方向一致，但仍需你确认是否有更直接的回路证据或文献依据要加入。
- “TH 抑制不太影响首会话但主要减慢后续增长”这一结论是否在全部统计口径下都稳健，需要你核对实际图和 p 值。

### 2.3 关于 RSPd 的定位
- 当前写法将 RSPd 定位为光信号偏好的上游转发区，而非迁移核心存储位点。这是结合图脚本和正文逻辑给出的较保守整合，但仍带明显推断成分。
- “单独抑制 RSPd 甚至略有提升”这一措辞建议你根据真实统计结果决定是否保留“略有提升”这种偏强描述。

### 2.4 关于机器学习类比
- 冻结层、可用性与更新效率的类比是为了增强讨论框架，但严格来说不是数据直接支持的结论。若担心审稿人认为跨领域类比过重，可缩减为一小段讨论。
