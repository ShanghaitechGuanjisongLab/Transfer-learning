## 2. 预处理（三档，全部跑，主分析预先指定）

### 2.1 基础链（三档共用）
```
raw F  →  ①QC  →  ②ΔF/F  →  ③档位特定去漂移  →  ④逐细胞 z-score  →  ⑤降维
```
- **② ΔF/F**：$F_0(t)$ = 60 s 滑动窗（480 帧 @8 Hz）的 **8 分位**；$\Delta F/F = (F-F_0)/F_0$
- **④ z-score**：用该场自身的中位数与稳健标准差（1.4826×MAD）

### 2.2 三档去漂移

| 档 | 做法 | 适用 |
|---|---|---|
| **P0 原始** | 什么都不做 | 敏感性对照（最保守地接近原始数据） |
| **P1 共模慢成分剔除**（**主分析**）| 只减去**共同模式**中的超慢成分：对群体均值 $\bar y(t)$ 做 0.01 Hz 低通得 $\bar y_{\rm slow}$，逐细胞回归 $y_i \sim a_i + b_i \bar y_{\rm slow}$ 后减去拟合值 | 只针对漂移的已知特征（共模 + 超慢），**不对非共模的慢动力学设上限** |
| **P2 高通** | 因果 Butterworth 0.01 Hz 高通（≈16 s 时间常数）| 最激进；会**明确截断** τ ≳ 16 s 的动力学 |

### 2.3 为什么 P1 是主分析
我们已实测：raw F 的漂移几乎全是**共模 + <0.02 Hz**（ALB 队列三次多项式可解释中位 15–52% 方差；群体均值 46–91% 能量在 <0.02 Hz）。
P2 的截止频率（0.01 Hz）与文献报告的线吸引子（τ = 100–150 s ≈ 0.001–0.0016 Hz）**频段重叠**，会连带删掉要证的东西。P1 只删共模，保留了非共模慢结构。

### 2.4 必须报告的识别边界
- **时间分辨率**：$\Delta t \approx 0.125$ s；GCaMP 衰减 τ ≈ 0.85 s ⇒ **< 1 s 的动力学不可分辨**
- **可识别 τ 上限**：P1 下受 session 长度限制，**τ ≤ 0.1 × 时长**（约 90–180 s）；P2 下 **τ ≤ 16 s**
- 任何 $\tau$ 报值若触到上限，须标 "≥ 上限"，不得当作点估计

### 2.5 反卷积（只用于报告 τ，不用于结构判定）
逐细胞 AR(1) MAP 反卷积（$g = e^{-\Delta t/\tau_{\rm Ca}}$，$\tau_{\rm Ca}$ 逐细胞估计）。
- **结构判定（C1/C2/C3-a/C3-b）一律在 ΔF/F 上做**，避免反卷积的非线性引入伪迹
- **报 τ 数值时**必须在反卷积后的信号上重做，并同时报 ΔF/F 上的值；两者不一致时以区间形式报告

## 4. 漂移场估计

局部线性回归（LOESS / kNN 加权最小二乘）：
$$\hat f(z) = \mathbb{E}[\dot z \mid z],\qquad \dot z_t = (z_{t+1}-z_t)/\Delta t$$
- 邻域 $k = 100$ 帧（约 12.5 s 等效），带宽由**留一场**交叉验证选（网格 50/100/200）
- 雅可比 $\hat J(z) = \partial \hat f/\partial z$ 用邻域内解析求导

## 5. C1 / C2：吸引子存在的判据（**五条全须满足**）

针对某一 session 与某一 d：

### A1 存在稳定不动点
在高占据区（占帧数前 20% 的邻域）内存在 $z^*$ 使
$$\|\hat f(z^*)\| < 0.25 \times \mathrm{median}\|\dot z\|$$
且 $\hat J(z^*)$ 全部特征值 $\mathrm{Re}\,\lambda < 0$。

### A2 净收缩（体积收缩）
$z^*$ 邻域内的散度
$$C(z^*) = -\nabla\!\cdot\!\hat f(z^*) > 0$$
**符号检验**：以鼠为单位，≥ 8/11 只鼠 $C(z^*)>0$。

### A3 回到吸引子（径向回复）
对 $r = \|z - z^*\|$ 分层（$r$ 的 20–60 分位区间），径向漂移分量
$$\hat f_r = \hat f(z)\cdot \frac{z^*-z}{\|z^*-z\|} > 0$$
**符号检验**：≥ 8/11 只鼠为正。

### A4 不是行为本身（关键反驳）
- 取**舔水率与奖赏历史匹配**的帧子集（每帧按前 2 s 舔次数、前 1 个 trial 是否命中分层，层内随机抽平）
- 在匹配子集上重算 A2、A3
- **要求**：A2、A3 在匹配子集上仍成立，且效应量下降 < 50%

### A5 超过零模型
A1–A4 的每个统计量在 §7 的四个零模型下重算，要求：
- 个体层面：≥ 8/11 只鼠 $p < 0.05$（$p$ 由 S1 相位随机化给出，$N_{\rm perm}=1000$）
- 组层面：Fisher 合并 $p < 0.01$

> **C1 成立** ⇔ 在 **P1 预处理、d=2 与 d=3** 下，A1–A5 **全部**满足。
> **C2 成立** ⇔ 同上，对 T1（以及独立地对 T2）。

### A6 吸引子类型（描述性，不作判据）
由 $\hat J$ 的特征值分类：
- **点吸引子**：全部 $\mathrm{Re}\lambda<0$，且 $|\lambda|_{\max}/|\lambda|_{\min} < 3$
- **线吸引子**：$|\lambda_1| \ll |\lambda_2|$（$\tau_1/\tau_2 > 5$），$\tau_1$ 触到可识别上限
- **旋转/焦点**：存在复特征值
类型只报不判，因为"任意吸引子都可以"。

## 6. C3：两个吸引子是否相似

### 6.1 C3-a 不变式比较（不需要细胞身份，n = 11）
对 (L, T1) 与 (L, T2) 各算三个描述子：

| 描述子 | 定义 | 相似度 |
|---|---|---|
| S1 类型 | §5-A6 的分类 | 一致率 |
| S2 时间常数谱 | 排序后的 $\log \tau_i$ 向量（i=1..d）| $1 - \|\Delta\log\tau\|/\|\log\tau\|$ |
| S3 占据几何 | $(r/\sigma_r)$ 的经验分布，$r=\|z-z^*\|$ | $1 - \mathrm{KS}$ 距离 |

**判据**：以鼠为单位的配对检验——同鼠 (L,T) 的距离是否**小于**跨鼠随机配对的零分布（$N_{\rm perm}=1000$）。
要求 **≥ 2/3 个描述子** 达到 $p < 0.05$。

### 6.2 C3-b 群体活动向量比较（需要细胞身份，n = 9）
- 吸引子向量 $a$ = 该吸引子占据的帧（后验占据 > 0.8 的帧）上，**逐细胞 z-score 的均值**，长度 = 交集的细胞数
- 相似度 $\rho = \mathrm{Pearson}(a_L, a_{T})$

**判据（两条都要）**：
1. **跨鼠零分布**：$\rho_{\rm within}$ > 跨鼠配对 $\rho_{\rm between}$ 的 **95 分位**，且 **≥ 7/9** 只鼠单独达到
2. **行为匹配后仍成立**：在 §5-A4 的匹配子集上重算，$\rho$ 下降 < 50%

> 说明：跨鼠零分布是**关键**。若 $\rho_{\rm between}$ 本身就很高（例如都存在"舔水相关"的强共模），则 $\rho_{\rm within}$ 再高也不构成"同一吸引子"的证据。

### 6.3 C3 成立
- **C3 强** ⇔ 6.1 与 6.2 同时成立
- **C3 弱** ⇔ 仅 6.1 成立（只能主张"同类型、同时标度"，不能主张"同一状态"）

### A.1 校准做了什么

对合成数据（已知真值）跑同一流水线，测量各判据的**假阳性率与功效**。

| 数据 | 构造 | 真值 |
|---|---|---|

| N-A2 | 秩-3 随机慢成分 × 随机载荷 + 打乱残差 | **无吸引子**（更严苛） |
| N-C | 极限环（有低维结构与径向收缩）| 有结构、**无不动点** |
| P-C | 线性 OU（τ = 10 / 40 s）| 有吸引子 |
| P-L | 线 OU（τ = 8 s / 中性）| 有吸引子 |

### A.2 结果

| 判据 | 在 N-A1 上 | 在 P-C 上 | 判定 |
|---|---|---|---|
| 散度 `div < 0` | 24/24 通过 | 通过 | **零判别力** |

问题在于**零模型具有完全相同的性质**。

### A.3 根因（本项目的核心方法学结论）

$$\text{独立 AR}(1)\ \Longleftrightarrow\ dx=-\frac{x}{\tau}dt+\sigma dW\ \Longleftrightarrow\ \text{OU 过程}$$

**OU 过程是一个具有稳定不动点的线性动力系统。** 因此：

> "存在稳定吸引子"这一命题，对**任何平稳数据**都成立，在纯观测数据上**不可证伪**。

局部线性回归的「回归到局部均值」偏倚与这一事实叠加，使得所有基于"漂移场 → 不动点 / 散度 / basin"的判据天然在零数据上通过。

### A.4 因此作废的判据

§5 的 **A1 / A2 / A3 / A6** 全部作废，不得作为"吸引子存在"的证据。
`attractor_core.py` 中相关函数保留，仅作**描述量**（报告数值，不用于判定）。

### A.5 唯一仍可证伪的"吸引子"版本

| 版本 | 可证伪内核 | 本项目数据 |
|---|---|---|
| 线吸引子 | **谱隙** $\tau_1/\tau_2 \gg 1$ | ❌ 相邻 $\lvert\lambda\rvert$ 比 **1.00–1.10**，无谱隙 → **已排除** |
| 点吸引子 | 无非平凡内核（OU 即满足）| ❌ 不可证伪 |
| 非线性 basin | 径向回复超线性 | ⚠️ 理论可测，但**功效不足**（见 A.2）|
| 因果吸引子 | 扰动后回归 | ❌ 无光遗传条件 |

### A.6 修订后的主张（**待签署**）

其中：
- **不再使用"吸引子 / attractor"作为结论性词汇**；可用 "metastable state"、"quasi-attractor"、"slow state"
- 必须明写："本数据无法区分稳定吸引子与线性平稳动力学（见附录 A）"

### A.8 D1 也失败：**零模型必须保留时间自相关**（2026-10-22）

**做法**：2 分量 vs 1 分量高斯混合的 ΔBIC，用"同 n 的 i.i.d. 高斯重采样"校准。

**结果**：

| 数据 | ΔBIC | null 95% | 判定 |
|---|---|---|---|
| **P-OU 线性（纯高斯 OU 潜变量）** | **+310** | −68 | **误判为双峰**（sep=2.48, w=0.34）|
| P-TG 电报双态 | +680 | −67 | 双峰（正确）|
| 真实 11 鼠 | +5400…+22257 | −88 | p 全部 0.024，但 sep 1.06–2.39、w 0.06–0.37 |

**根因**：真实 OU 的马氏距离分布要 **12.5 个 τ** 才平滑；我们只有 500 s 而 τ = 40 s，
样本天然"成团"。而 i.i.d. 高斯零模型**不含自相关**，因此无法复现这种成团 →
**任何慢过程都会被判成结构**。

**这是本项目四次校准失败（A2 / basin / D3 / D1）的共同根因**：

> **零模型若不保留观测数据的时间自协方差，就会拒绝一切慢过程。**

**唯一通过校准的做法**：零模型必须与数据**匹配自协方差**。
本项目此前用过且有效的两种正是这一类：
- **相位随机化**（FFT 保功率谱 ⇒ 保自协方差）
- **整体环形平移**（保逐细胞自相关）

### A.9 因此的最终技术路线

不再发明新的"吸引子判据"。改为：**在自协方差匹配的零模型下，检验唯一一个统计量**——

> **条件回归速率**：偏离主导状态后，回到该状态的速率是否快于相位随机化零模型。

理由：
1. 它是**唯一**在非线性（真实吸引子）与线性平稳（OU）之间真正有差别的量：OU 的回归速率完全由自协方差决定，超出即为非线性。
2. 我们**已有**这类结果：excursion/cloud = 23% vs 零模型 5%，11/11 只鼠 p<0.05（见笔记 §(hh) 之前记录）。
3. 它可证伪、零模型明确、且不依赖"不动点/散度/basin"这些已被证明恒真的量。

**据此的主张（最终版，待签署）**

> **C1′/C2′**：learned 与 transfer 两阶段各自存在一个占据主导的群体状态；偏离后回归的速率显著快于自协方差匹配零模型（$p<0.05$，≥8/11 只鼠）。
> **C3**：该状态的群体活动向量在两阶段高度相似（同鼠同细胞），相似度超过跨鼠零分布 95 分位（≥7/9 只鼠）。
>
> 结论中**不使用 "attractor"**；使用 "metastable state whose return dynamics exceeds linear-stationary expectations"。
> 必须明写：本数据无法区分稳定吸引子与线性平稳动力学（附录 A.3）。

### A.12 cue 作为扰动：cue 不变的不动点检验（2026-10-24）—— **不可判定（功效不足）**

**动机**（用户提出）：cue 本身就是一种**重复、分级、可量化**的扰动协议，
因此"无扰动实验"不等于"无法检验 basin"。若不同 cue 激发的偏移都回到**同一个**不动点，
则该不动点是内部状态，而不是某条感觉通路的产物 —— 这直接对抗"所谓吸引子只是刺激响应"。

数据来源：`ALB` 的 `LAu` / `LAuW` 会话（10 只鼠），同一会话内有
`AudioOnly` / `LightOnly` /（`LAuW` 另有）`WaterOnly` 三种独立扰动通道。

#### A.12.1 v1 失败：VAR 求不动点在短窗上发散

每刺激局部拟合 $\Delta x=c_s+A_s x$，取 $x_s^*=(I-A_s)^{-1}c_s$。
回落窗仅 ~3 s，$A$ 的最大特征值 ≈0.99 ⇒ $(I-A)$ 近奇异 ⇒ $x^*$ 对 $A$ 的微小误差爆炸放大。
实测 $D_{\rm floor}$（同种刺激奇偶分半）中位 **12.4**，比 $D_{\rm obs}$ 还大 ⇒ 不可用。
与 vtf0233/Transfer 的 `dist`=3184 是同一病理。**教训：短窗上不得用 $(I-A)^{-1}c$。**

#### A.12.2 v2（有界统计量）

$$D(\tau)=\frac{\lVert m_A(\tau)-m_B(\tau)\rVert}{\text{spread}},\quad \tau\in[0,3.5]\,\mathrm{s}$$

$D_{\rm peak}=\max_{\tau\le2.5}D$，$D_{\rm late}=\overline{D}_{2.0\text{–}3.0\,\mathrm{s}}$，
噪声地板 = 同种刺激奇偶分半的平均轨迹之差。

**结果（22 个刺激对）**

| 量 | 中位 |
|---|---|
| $D_{\rm peak}$ | 0.654 |
| $D_{\rm late}$ | 0.581 |
| **噪声地板** | **0.615** |

$D_{\rm peak}\approx$ 地板。按预注册的 d 滴定复核，**d = 2 / 3 / 5 / 10 全部如此**
（$D_{\rm peak}$ 中位 1.26 / 0.90 / 0.77 / 0.65，地板 1.06 / 0.97 / 0.88 / 0.76；
$D_{\rm peak}>1.5\times$地板的仅 8/7/6/6 只，共 22 对）。

**判定：⛔ 不可判定（功效不足），不得报阴性，也不得报阳性。**
根因：naive 动物每种刺激仅 20–30 个 trial，刺激特异的群体平均偏移与测量噪声同量级；
分母（$D_{\rm peak}$）本身就是噪声，`ratio` 这个统计量在此失效。

#### A.12.3 结论与替代

1. **本数据无法在 naive 会话内检验 cue 不变性。** 该检验作废，不再使用。
2. **但这个科学问题没有丢**：它与 C3（Learned vs Transfer 的吸引子相似性）**几乎是同一个问题**——
   若两个阶段的吸引子相同，则声驱动与光驱动的偏移自然通往同一点。
3. C3 是**功效充足**的版本：Learned 与 Transfer 的线索响应在响应子空间里 d′ 中位分别为
   2.64 与 1.53（Step5），远强于 naive 会话。
4. 另一条可选轴：LAB 的 `AuAuw`（AudioWater+AudioOnly）与 `LLw`（LightWater+LightOnly）
   会话在同一 session 内有"给水/不给水"两种同线索 trial，可检验**奖赏不变性**，
   且响应强、功效足。代价是需另导这两类 block。

### A.14 A4 行为匹配：C3-b 的 ρ **不是**舔水活动造成的（2026-10-24，**已执行**）

**威胁**：两个阶段小鼠都在"线索→舔水→得水"。若部分细胞的 $a_i$ 高只因编码舔舐，
则 ρ 高是平凡的（共享舔水相关活动），与内部状态无关。

**做法**（`Step21_A4_BehaviorMatch.py`）。舔水率 = 每帧前 2 s 的 CD2 起始数
（阈值 median + 0.5×(max−median)，最小间隔 0.15 s，项目一贯口径）。

- **A4a 分层匹配重算**：按舔水率分 5 箱，箱内抽样使两阶段分布匹配，
  在匹配后的帧子集上**重跑整条流水线**（ΔF/F → P1 → z → PCA → core → a）
- **A4b 回归剔除**：逐细胞把 z 对舔水率线性回归取残差，再算 a

**结果**

| 量 | MOp2/3，11 只鼠，中位 |
|---|---|
| ρ_full | 0.468 |
| **ρ_A4a（匹配）** | **0.471**（下降 **+0%**）|
| **ρ_A4b（剔除）** | **0.453**（下降 **+0%**）|
| 下降 <50% 的鼠 | **11/11**（A4a 与 A4b 均如此）|

逐鼠变化范围 −6% ~ +9%，**ρ 基本不动**。

**诊断（说明这不是平凡通过）**
核心帧并非无舔水：核心帧舔水率中位 (L) 0.43 vs 全体 0.57；(T) 0.40 vs 0.43。
核心帧有实质舔水率，匹配与剔除都是非平凡操作，ρ 仍然存活。

**限定**：A4 只剔除舔水率的**线性**效应；非线性的运动学成分、以及未被 CD2 捕捉的
运动，仍未排除。此限定须写入论文。

### A.16 同会话内不同刺激的构型对比 —— **全部不可判定（估计不可靠）**（2026-10-24，**已执行**）

**这是设计上最强的对照**：在 `LAu` / `LAuW` 会话里，**同一 session、同一批细胞、同一天、同一增益**，
只有输入不同（`AudioOnly` / `LightOnly` / `WaterOnly`）。任何差异只能来自输入，
任何相似性也只能来自"构型与输入无关"——这正是跨 session 对照排除不掉的混淆。

**统计量**（细胞空间，不做 PCA）
- $a_s=\mathbb E[z_i\mid\text{刺激 }s\text{ 后 0–1.5 s}]-\mathbb E[z_i\mid\text{全帧}]$
- $D=\sqrt{\overline{(a_A-a_B)^2/(\mathrm{SE}_A^2+\mathrm{SE}_B^2)}}$（$D\approx1$ ⇒ 只差在噪声）
- $\rho_{\rm cross}$，以及同刺激奇偶试次分半的可靠性 $\rho_{\rm rel}$ 作为上限参照

**结果（ALB 6 只 LAuW + 4 只 LAu + LAB 4 只 LAuW，共 68 个刺激对，两层）**

| 层 | n | ρ_cross 中位 | **可靠性中位** | D 中位 | 判定 |
|---|---|---|---|---|---|
| MOp2/3 | 34 | −0.023 | **0.128** | 1.14 | **不可判定 34/34** |
| MOp5 | 34 | −0.010 | **−0.019** | 1.14 | **不可判定 34/34** |

**根本原因：$\rho_{\rm rel}$ 中位仅 0.128 ⇒ 刺激特异的群体状态向量约有 87% 是噪声。**
在估计本身不可靠时，任何 $D$ 或 $\rho$ 的解读都无意义（$D\approx1.1$ 看似"无差别"，
但这只是功效不足，不能当作"构型与输入无关"的证据）。

**为什么不可靠**：naive 动物每个刺激仅 20 个 trial，且响应本身弱
（A.12 已测：峰值/SE 中位 2.3）。要可靠估计 $a_s$ 需要每刺激 ~60–100 个 trial，
或更强的响应（已学动物），或更低维的摘要。

**⇒ 这条线到此结束。** C3 的四条路线（不变式 / 状态向量 / RSA / 同会话刺激）全部
落在"不可判定"或"无显著状态特异性"上。

### A.18 M6 是否为"定型诱发轨迹"的几何产物（2026-10-24，`Step31` + `Step31b`）

#### 触发原因

`ρ_rot = ‖(C_τ−C_τ^T)/2‖_F / ‖(C_τ+C_τ^T)/2‖_F` 度量的是**滞后协方差的不对称度**。
它有一个不需要旋转流场就能非零的来源：

> A.17 已测出 trial 诱发响应是一条**高度可重复的弧线**（3 s 升至峰、半衰 6 s、15–18 s 回基线）。
> 同一条弧被反复遍历，滞后协方差天然不对称 ⇒ `ρ_rot > 0`。

相位随机化会摧毁跨通道相位对齐（也就摧毁这条弧），因此**该零模型无法排除此解释**。
A.17 观察到"P2 更高通 ⇒ 超额×3"正是沿这个方向加分，故必须单独检验。

#### 设计

同一批帧（截断到 25 s 的 trial 段）、同一 `lag=16`、同一奇偶分半 seed：

| 量 | 构造 |
|---|---|
| `obs` | 原始 10 维 PC 轨迹 |
| `arc` | 只保留 trial 锁时平均轨迹 $R(k)$，复制到每个 trial（零 trial 间变异）|
| `res` | $X - R(k)$，去掉定型轨迹后的残差 |

`obs` 与 `res` **各配自己的**逐维相位随机化零模型（$N_{\rm PERM}=20$；残差谱已变，不能套用 obs 的零模型）。

关键逻辑：**两条证据的强度不同**

* **arc 部分是有歧义的**——均值轨迹本身由流场生成，所以它的不对称既可能是"自治流场的旋度"，
  也可能只是"被输入反复驱动的同一条弧"。仅凭 arc 无法区分。
* **res 部分没有歧义**——一条被反复重放的确定性轨迹**不可能**在 trial 间偏差里产生旋转；
  残差里若仍有旋转，只能来自**局部线性动力学（Jacobian）的非对称部分**。
  这是比原判据**更严格**的口径。

> 非对称（旋转/非正规）结构（超额 +0.037，p=1.4e-5，27/33 只鼠同向）；
> 该结构约一半可从定型诱发轨迹得到解释，另一半不能。
> 在 MOp5，扣除定型轨迹后该结构不可检出。

#### 已知缺陷

1. 扣除 trial 平均轨迹会**同时**扣掉真实动力学中的可重复成分（若轨迹确由确定流场生成），
   因此 res 口径**偏保守**；arc 口径偏宽松。真实值介于两者之间。
2. `arc` 用 25 s 截断段估计，末段（25 s 后）无 arc 估计，故与 A.17（全长段）的 obs
   数值不完全可比（0.252 vs 0.218）。
3. 残差零模型在 **PC 空间**做相位随机化（不再回到细胞空间重做 PCA），
   与 A.17/Step17 的零模型不完全同构；但两者都是"保谱、毁跨维相位"。
4. 未检验 `res` 的超额是否随预处理档位（P0/P2）变化——若要写进论文应补 P0/P2。

### A.19 T3 功效预扫：先量功效，再决定是否签协议（2026-10-25，`Step33`/`Step33b`）

#### 动机

A.12–A.18 之后，T3 是唯一还没做的"阶梯 4（自主性）"。但 A.18 之前的 Step28–30 已经发现：

* 群体平均响应峰在 **3.0 s**，单 trial 幅度峰在 **7.25 s**（IQR 4.5–10.25），峰后半衰 **≈6 s**，**15–18 s** 才回基线；
* 单 trial 偏离一直增长到 ~7 s，**响应是持续 ≥10 s 的慢坡**，不是瞬变；
* 因此 T3 原稿的"峰值后 2.5 s"窗口（落在 3–5.5 s）覆盖的是**平台期**，不是回落相；
* 且 H1 的核心变量 $s$ 与状态高度共线。

结论：**必须先量功效，再决定签不签**。原稿把功效门槛放在最后（跑完再查），顺序不对——它允许"试很多窗口、恰好有一个显著"。

#### 设计（只用合成数据）

生成结构全部来自实测：2 维 cue 响应子空间、该子空间内拟合的 VAR(1) $(c,A,\Sigma)$、实测平均响应 $\mu_2$ 逐 cue 注入。
隐藏驱动：AR(1)，$\tau_u=20$ s，$z_{t+1}=c+Az_t+\beta u_t d+\epsilon$。
统计量：$\Delta z^\tau=z_{t+\tau}-z_t$，$\tau=1$ s；$M_0$=二次多项式，$M_1$=$M_0$+$s$ 的 4 分箱；按 trial 分组 5 折 CV。
功效：用 $\beta=0$ 的 $\Delta R^2$ 分布标化后与单侧 95 分位比较。33 session，B=30–40。

#### ⚠ 实现错误（必须记录）

`Step33` 第一版把**真实数据的 $\Delta z$** 当作模拟数据的回归目标
（`delta_r2(Zs, y_lag, ...)` 中 `y_lag` 由真实 `Z2` 预先算好）。
这使"模拟特征 vs 真实目标"混用，**`Step33` 的功效表全部作废**。
`Step33b` 已改为从模拟数据自身计算 `ys`，以下只用 `Step33b` 的结果。

（另有两处较小错误已修：① one-hot 箱号误用绝对时间下标 `np.arange(n)` 而非 `sidx`，导致窗口内几乎全部落同一箱、$\Delta R^2\equiv0$；② 一度把 $\beta$ 的尺度误读为"很强的驱动"，实际 `scale`=0.446 而 $\Delta z$ 的 sd=1.82，β=0.15 仅相当于信号的 ~4%。）

#### 三条结构性发现

**① 上升相窗口的零模型基线不为零**
`0-12` 在 β=0 时 $\Delta R^2$ 中位 = **0.2015**。原因是诱发斜坡让 $s$ 与"沿轨迹位置"强相关，
$s$ 分箱确实带来额外预测力 —— 这是**伪装的"历史效应"**。
⇒ 这一数字（20%）定量地说明了为什么**上升相绝不能用于自治性检验**，比 A.12 的定性论证有力得多。

**② 功效随驱动强度非单调，且回落相中驱动反而使 ΔR² 下降**
`7-16`：$\Delta R^2$ 从 β=0 的 +0.0248 降到 β=9 的 −0.0104。
机制：驱动强到一定程度会被**状态吸收**（$z$ 里已含 $u$ 的信息），条件于 $z$ 后历史不再有增量；
同时驱动把轨迹推离定型弧，使 $s$ 更不预测位置。
⇒ "增大效应量就能检出"的直觉是错的，T3 只在一个"可检出带"里有效。

**③ 最关键：τ_u=20 s 的驱动几乎不影响 1 s 差分**
即使 β=9（每帧注入 ≈4.0，约为 $\Delta z$ 的 sd 的两倍），**oracle R² 也只有 0.052**。
原因：AR(1) 时间常数 20 s 的驱动在 1 s 内几乎不变，而 $\Delta z$ 是**变化量**；
驱动的**水平**被 $z$ 吸收，**变化**又极小。

⇒ **T3 原稿的阳性对照（$\tau_u=20$ s）与其统计量（$\Delta z$ at $\tau\le2$ s）在量纲上不匹配。**
这是独立于窗口选择的第二个设计缺陷。

| 问题 | 裁决 |

| T3 能否在本数据上回答自治性？ | ❌ **不能**。有效窗口最大功效 0.21 < 0.5 |

| T3 的最终处置 | **不签署、不运行**，作为"不可判定（功效不足）"写入论文 |

**建议写入论文的表述**：
> 在本数据的采样条件下（8 Hz、GCaMP 衰减 ≈0.85 s、单 trial 响应持续 ≥10 s、每场 30 trial），
> 状态充分性检验在可用的回落相窗口内最大功效为 0.21（合成数据，β 扫描 + 33 session 实测生成模型）。
> 因此本数据**无法判定**群体动力学是否自治，需要更高采样率、更多 trial，
> 或改用与候选驱动时间尺度匹配的统计量。

| 阳性对照改用 $\tau_u=2$–5 s | 与 $\tau=1$ s 的差分匹配 | 但此时"输入衰减"假设本身变了 |
| 增加 trial 数（>100/场）| $\Delta R^2$ 的检出能力 ∝ trial 数 | 需新数据 |

三条都不能用现有数据分析出来 ⇒ **现有数据上 T3 到此结束。**

#### 已知缺陷

1. `Step33` 实现错误已作废，本节的数字全部来自 `Step33b`；两点间不一致（如 β=0 时 0-12 的 0.109 vs 0.202）就是该 bug 的表现。
2. B=30，功效估计的抽样误差约 ±0.03（n=990）。
3. 只做了 pooled 层；MOp2/3 与 MOp5 未单独扫（预期不会改变结论，因为限制来自 trial 数与响应形态）。
4. 冒烟测试阶段曾用**真实数据**算过一次 `[0,12]` 的 $\Delta R^2$=0.199（1 个 session）。该值未用于任何结论，但已构成"预扫不完全盲"的瑕疵，如实记录。

### A.20 勘误：诱发响应的潜伏期结构（2026-10-25，`Step34`/`Step35`/`Step36`）

#### 触发

A.19 及之前反复使用"群体平均诱发响应峰在 **3.0 s**"。该表述被质疑与实测经验不符。
核查后确认：**"3.0 s" 不是峰宽，是曲线 argmax；而该 argmax 不稳健，必须撤回。**

#### ① 对齐核查（先排除偏移）

`idx_cue` 与 **CD1 上升沿**逐一比对（990 个 cue，33 session）：

| 量 | 结果 |
|---|---|
| 偏移中位 | **+0.000 s** |
| 偏移范围 | 0.00 – 0.13 s |
| \|偏移\| < 0.5 s 的比例 | **100%** |

⇒ **不存在 3 s 或任何系统性偏移**。"晚峰"不是对齐造成的。

#### ② 峰潜伏期依口径而变（说明曲线是宽平台）

| 口径 | 峰潜伏期 |
|---|---|
| A. PSTH（跨细胞平均 z）| **1.85 s** |
| B. 跨细胞平均 \|z\| | 3.25 s |
| C. ‖R‖/√nCell（A.19 原口径）| 2.85 s |
| D. 仅响应细胞 PSTH | 3.25 s |
| E. ΔF/F PSTH（未 z 化）| 2.35 s |
| F. ΔF/F mean\|·\| | 2.50 s |
| G. 逐细胞峰潜伏期中位 | 2.75 s（IQR 1.65–4.00）|

PSTH 数值：−0.4 s: −0.003，0.6 s: 0.015，1.0 s: 0.025，1.5 s: 0.052，**2.0 s: 0.070**，
2.5 s: 0.044，3.0 s: 0.043，3.5 s: 0.043，4.0 s: 0.056，5.0 s: 0.047。
⇒ 1.5 s 之后是一条**几乎平坦的平台**（0.043–0.070），argmax 落在哪全是噪声。

#### ③ 逐细胞起始潜伏期（关键，`Step36`）

准则：基线 [−1,0] s 的稳健 SD（1.4826×MAD），τ>0 首次连续 3 帧 \|z−base\| > 3σ。

| 层 | nCell | 有响应 | **起始中位** | IQR | <1 s | 1–2 s | >2 s | 峰中位 |
|---|---|---|---|---|---|---|---|---|
| MOp2/3 | 7107 | 5539 | **0.70 s** | 0.20–1.55 | **61%** | 22% | 17% | 2.55 s |
| MOp5 | 8211 | 6073 | **0.80 s** | 0.20–1.90 | **55%** | 23% | 23% | 2.90 s |

**这才是正确图像**：
> 细胞**起始**很早（中位 0.70 s，61% 在 1 s 内），这与实测经验一致；
> 但响应**不是瞬变，而是持续上升**，直到 **2.55 s** 才见顶，然后缓慢回落（峰后半衰 ≈6 s，15–18 s 回基线）。

⇒ "峰在 3 s"作为 argmax 不算错，但把它当作"诱发响应峰"**会误导**：真正的早期成分确实在 1 s 内。

#### ④ 晚峰不是奖赏锁定（`Step35`）

| 检验 | 结果 |
|---|---|
| cue → 最近一次 GiveWater | 中位 **21.83 s**（IQR 9.80–31.59，10–90% 2.29–52.76）|
| hit PSTH@3s | 0.049 |
| **miss PSTH@3s** | **0.077（更大）** |

⇒ 给水在时间上既太晚又太分散，且**未命中 trial 的晚成分不比命中弱**。
**晚峰不是给水/奖赏相关**，是响应自身的持续增长（可能含运动/觉醒等慢成分，未分离）。

#### 裁决与措辞修正

| 原表述 | 修正后 |
|---|---|
| "群体平均诱发响应峰 3.0 s" | **"起始中位 0.70 s（61% <1 s），之后持续上升至 2.55 s 见顶，半衰 ≈6 s，15–18 s 回基线"** |
| "峰在 0–1.5 s"（`Step14` 的 `PEAK_WIN`）| 该窗口取到的是**上升沿上的点**，不是峰 |
| "2.5 s 回落相"（T3 S1）| 峰在 2.55 s 之后才开始衰减 ⇒ 回落相应 ≥ 3–4 s；A.19 的功效预扫已据此改用 7–16/9–18 s |

**对既有结论的影响**：
* T3 的功效预扫（A.19）结论不变——它本来就是按"无回落相"处理的。
* M1 的解释**进一步削弱**：`PEAK_WIN=(0,1.5)` 落在上升沿，`R` 中位 0.75 说明它测的是上升方向的旋转，不是残留。
* τ1 ≈ 8.6–17 s 与"持续响应衰减 ≈6 s 半衰"一致 ⇒ 仍不应解释为独立的网络慢模态。

### A.21 目标 2：跨阶段反对称算子的直接比较（2026-10-25，`Step37`）

#### 为什么走这条路线

`ρ_rot` 把反对称结构压成一个标量，判别力不足（C3-a、RSA、谱形状全部失败）。
但 $A_\tau=\tfrac12(C_\tau-C_\tau^\top)$ 是**每个细胞对上一个数**，保留空间结构。
在 CellUID 交集上可逐元素比较，直接检验"是不是同一个非梯度结构"。

#### 设计

| 项 | 设定 |
|---|---|
| 细胞 | 三阶段 CellUID 交集，且三阶段均 MOp2/3（104–339 个/鼠）|
| 预处理 | P1 → 逐细胞稳健 z-score（使每细胞方差可比）|
| 去弧 | 残差 = $Z-R(t-{\rm cue})$，$R(k)$ = trial 锁时平均（A.18 证明必需）|
| lag | 16 帧（τ ≈ 2 s）|
| 相似性 | 两阶段 $A_\tau$ **上三角**逐元素 Pearson $r$ |
| 零模型 | 打乱一阶段细胞标签（$PAP^\top$），N_PERM=300。**这里标签置换有效**——检验的正是"同标签对应"（与 RSA 情形不同）|
| 可靠性天花板 | 奇偶分半各算一次 $A_\tau$，上三角相关，Spearman-Brown 校正 $r_{\rm full}=2r_h/(1+r_h)$ |

预声明判读：两阶段可靠性均 ≥0.5 且跨阶段 $r$ > 零模型 95% ⇒ 共享；可靠性 <0.5 ⇒ **不可判定**。

#### 结果（11 只鼠）

| 鼠 | nCell | rel L | rel T1 | rel T2 | r(L,T1) | 零95% | p |
|---|---|---|---|---|---|---|---|
| vtf0233 | 253 | 0.12 | 0.69 | 0.18 | −0.003 | 0.009 | 0.661 |
| vtf0352 | 307 | 0.08 | 0.14 | 0.18 | +0.061 | 0.008 | 0.003 |
| vtf0353 | 104 | 0.23 | 0.14 | 0.15 | −0.005 | 0.028 | 0.575 |
| vtf0354 | 156 | 0.16 | 0.31 | 0.21 | +0.105 | 0.020 | 0.003 |
| vtf1233 | 339 | 0.19 | 0.12 | 0.10 | +0.076 | 0.008 | 0.003 |
| yqn0020 | 269 | 0.05 | 0.06 | 0.04 | +0.027 | 0.007 | 0.003 |
| yqn0133 | 125 | −0.08 | 0.18 | 0.32 | +0.006 | 0.018 | 0.279 |
| yqn0240 | 282 | 0.14 | 0.10 | 0.17 | +0.075 | 0.009 | 0.003 |
| yqn0411 | 210 | 0.09 | 0.34 | 0.11 | +0.103 | 0.011 | 0.003 |
| yqn1018 | 183 | 0.26 | 0.30 | 0.47 | **+0.205** | 0.012 | 0.003 |
| yqn1130 | 141 | 0.24 | 0.03 | 0.27 | +0.097 | 0.020 | 0.003 |

**可靠性**：33 个阶段估计的中位 **0.16**（范围 −0.08–0.69），**仅 1/33 ≥ 0.5**。

#### 判读（分两层）

**① 预声明判据：11/11 不可判定**
可靠性普遍只有 0.1–0.3，低于 0.5 门槛。**不是因为"不相似"，而是因为逐元素估计本身不可靠。**

**② 但存在一致的方向性信号（须谨慎表述）**

| 统计 | 值 |
|---|---|
| r(L,T1) 中位 | **+0.075** |
| 为正 | **9/11**（符号检验 **p=0.033**）|
| 超置换零模型 95% | 8/11 |
| 去衰减估计 $r/\sqrt{\rm rel_L\,rel_{T1}}$ | 中位 **0.55**（范围 −0.03–1.07，**不稳定**）|

在经典测量误差模型下，观测 $r\approx\rho_{\rm true}\sqrt{\rm rel_L\,rel_{T}}$；代入中位可靠性 0.16 得 $\rho_{\rm true}\approx0.47$。

**⇒ 可写的表述**：
> 三阶段 CellUID 交集上，细胞身份特异的反对称结构与 Learned→Transfer 的一致性在 9/11 只鼠中为正（符号检验 p=0.033），
> 去衰减估计 ρ≈0.5；但逐元素估计的奇偶分半可靠性中位仅 0.16（仅 1/33 达 0.5），
> 因此**无法在预注册判据下确认共享**。

#### 方法学要点（重要）

置换零模型在 45k 维上极窄（95 分位仅 0.007–0.028），**p=0.003 已是 300 次置换的下限**，
几乎不含信息。这类分析必须报**效应量 + 可靠性**，不能报 p。
（与 A.18 的教训同源：零模型的形式决定了可解释性。）

#### 局限

1. 可靠性那么低时，Spearman-Brown 去衰减极不稳定（范围 −0.03–1.07 已说明问题）。
2. vtf0233 的 Transfer 可靠性 0.69 反而给出 r=−0.003：可靠性高但无对应，说明**共享不是普适的**。
3. 只做了 MOp2/3；MOp5 未做。
4. 每阶段仅 30 trial ⇒ 逐对估计的自由度不足。要提升到可靠性 0.5 需约 3–4 倍数据量。

#### 对目标 2 的最终意义

这是第五条路线，同样落在**不可判定**。但它比前四条前进了一步：
它给出了一个**可量化的方向性信号**（9/11 为正，p=0.033，去衰减 ρ≈0.5），
而不是像 C3-a/RSA 那样完全没有判别力。

**结论**：目标 2 在现有数据上不可判定；若未来增加 trial 数（约 3–4 倍）或鼠数，
这条路线是**唯一已验证有方向性信号可依托**的候选。

### A.23 训练进度序列：排除"新奇性/训练进度"解释（2026-10-25，`Step39`/`Step39b`）

#### 动机

A.22 发现三阶段观测旋转量相同，但相对零基线的比值不同：**Transfer 1.38 / Final 1.13 / Learned 1.11**。
两个"晚期"状态都 ≈1.1，只有"首次接触新关联"的 Transfer 在 1.4。

### A.24 目标 2 第六条路线：旋转子空间比较（2026-10-25，`Step40`）——**首次得到"部分共享"**

#### 为什么换统计量

A.21 逐元素比较 45k 个 `A_τ` 上三角元素，**奇偶分半可靠性中位仅 0.16**（1/33 ≥0.5）。
问题不是零模型，而是**自由度远大于数据**。

新统计量：`A_τ` 是实斜对称矩阵，奇异值成对出现，每对张成一个**旋转平面**。
取前 m 个右奇异向量 $V_m$，用**子空间重叠**比较：

$$\mathrm{overlap}(W_1,W_2)=\frac{\lVert W_1^\top W_2\rVert_F^2}{m}\in\Big[\tfrac{m}{n},\,1\Big]$$

自由度从 4.5 万降到几个数；且**子空间对向量符号与基内旋转无歧义**（避开 C3-b 的翻号陷阱）。

三重对照：**天花板** ceiling（阶段内奇偶分半）、**跨阶段** cross、**零模型** null（打乱细胞标签，N_PERM=200）。

|---|---|---|---|---|---|---|
| 2 | 0.026 | **0.214** | 8.4× | 0.088（8/11）| 0.072（10/11）| 0.146（9/11）|
| 4 | 0.041 | **0.247** | 6.1× | 0.158（9/11）| 0.132（11/11）| 0.148（9/11）|

* **cross/天花板 ≈ 0.51（m=2）/ 0.61（m=4）**；ratio ≥ 0.8 仅 1/11（m=2）、4/11（m=4）

#### 关键逻辑：cross < 天花板是**保守**证据

## A.28 `fixed_point()` 转置勘误：确认是 bug，影响 <0.01，**待重跑**（2026-10-25，Step45）

#### 问题

`Step14_Unified.fixed_point` 与 `Step18_CueInvariantFixedPoint.fit_fixed_point` 都写成

```python
np.linalg.solve((np.eye(d) - A).T, c)      # 解 (I - A)^T x = c  →  (I - A^T)^{-1} c
```

但 `fit_var1` 的模型约定是 $x_{t+1} = A x_t + c$（`sim_var1` 里 `Z[t] = c + A @ Z[t-1] + e`），
不动点应满足 $(I-A)x = c$，即 $(I-A)^{-1}c$。**当 A 对称时二者相同，非对称时不同。**

#### 判定（不依赖任何约定，只看向量是否真的是不动点）

$r(x) = \|Ax + c - x\| / \|x\|$，真正的不动点应满足 $r \approx 0$。

| 解法 | r 中位（33 session，MOp2/3，P1） |
|---|---|
| 现有 `solve((I−A).T, c)` | **1.80e−02** ⇒ **不是不动点** |
| 正确 `solve(I−A, c)` | **9.59e−17** ⇒ 机器精度 |

#### 影响量化

| 量 | 现有 | 修正后 |
|---|---|---|
| A 非对称度 `‖A−Aᵀ‖/‖A‖` 中位 | 0.026 | — |
| 两不动点差异 / spread 中位 | — | **0.006** |
| `dist` 中位 | 0.391 | **0.387** |
| `dist < 1` 计数 | 32/33 | **32/33** |
| 两种 dist 相关 | — | **r = 1.0000** |
| 逐 session `<1` 判定一致 | — | **33/33** |

⇒ **所有已报告的定性结论不变**（A.17 的"dist<1 三档全成立"、dist 中位 0.39 等）；
只有小数第 3 位会变动。

#### 受影响的脚本与产出

| 脚本 | 用途 | 产出 |
|---|---|---|
| `Step14_Unified.py` | 主流程 | `_step14_unified.json` |
| `Step16_LayerSplit.py` | P1 的 dist | `_step16_layersplit.json` |
| `Step18_CueInvariantFixedPoint.py` / `Step18b` | 不同 cue 的不动点比较 | `_step18*.json` |
| `Step26_PreprocSensitivity.py` | P0 / P2 的 dist | `_step26_preproc.json` |
| `Step27_DistNull.py` / `Step27b` | dist 的零模型 | `_step27*.json` |
| `Step43_PhaseGeometry.py` | dist 按阶段汇总 | `_step43_*.csv` |

**不受影响**：M6（ρ_rot，Step31/32）、Q/τ（Step17b/26 的谱）、C3 全部路线、子空间（Step40/41/42）。
Step16 的 `Q` 本来就是已撤回的 lag=1 口径，与本节无关。

#### 修复方案（一行）

```python
return np.linalg.solve(np.eye(d) - A, c)
```
