# 解码器与复用细胞的关系研究

> 研究问题：跨任务解码（Train → Transfer）是否依赖于"复用细胞"——即在 Learned（训练）与 Transfer（测试）阶段都保持**活跃**的细胞？找出这些细胞、剔除后重做解码器，观察解码效果变化。

## 1. 研究问题
- 钙成像解码器（Cue / Choice）在 Transfer（LightWater）阶段的表现，是否由"两阶段都活跃的复用细胞"承载？
- 若能找出复用细胞并剔除，解码效果（MI、概率倾向分离）如何变化？

## 2. 关键定义
- **Learned 阶段**：AudioWater 训练集 `trainAW`（Naive + Learned + 未标注，排除 Recall）——作为"已学会"阶段的代表。
- **Transfer 阶段**：LightWater `Transfer` block。
- **活跃细胞**：刺激诱发响应 = 刺激后窗口（t∈[0.3, 0.96] s）平均钙信号 − 基线（t<0）平均钙信号。默认取 **响应 > 0**（正响应）为活跃（阈值可调）。
- **复用细胞**：在 Learned 与 Transfer 两阶段都活跃的细胞（CellUID 交集）。

## 3. 方法
1. 每鼠分别计算每细胞在 Learned、Transfer 的刺激诱发响应（逐 trial 平均后按细胞聚合）。
2. 复用细胞 = Learned 活跃 ∩ Transfer 活跃。
3. 解码对比（以 Choice cfg2 = AudioWater 训练为主；Cue cfg2 可扩展）：
   - **基线**：全部细胞训练/解码；
   - **剔除复用**：从特征中剔除复用细胞（只保留非复用细胞）后重新训练/解码；
   - 比较 OOF MI（列1）与 Stage2（Transfer light hit / light miss）倾向分离。
4. 报告每鼠复用细胞数量、占比，以及剔除前后解码指标变化。

## 4. 结果（全面版）
脚本：`CellReuseStudy_All.m`（Cue cfg2 与 Choice cfg2；活跃定义 4 种：`>0`、`>0.1`、显著（t 检验）、`top30%`；对照：剔除复用 / 保留复用（反向）/ 随机剔除同数量 ×20 次）

**复用细胞占比**（Learned∩Transfer 活跃）依赖定义：`>0` 约 33%（19.9–50.7%）；`>0.1` 约 6–25%；显著 约 1–5%；`top30%` 约 8–16%。

**结论（跨 4 种活跃定义、Cue 与 Choice 两个解码器一致）**：
- 剔除复用细胞后，OOF MI 与 Stage2 倾向分离普遍下降，但**从未显著超出"随机剔除同等数量细胞"**（pMI>0.95 的鼠数 0–1/9；pS2>0.95 的鼠数 0–1/9，无任何定义下普遍显著）；
- 保留复用（反向，只留复用细胞）的解码通常低于全细胞（因细胞数大减），但不支持"复用细胞特异承载解码信号"；
- **因此：复用细胞（Learned∩Transfer 活跃）对解码的贡献未特异性地超出随机预期**——解码信号广泛分布于细胞群，而非集中在该批复用细胞上；Cue 与 Choice 均如此，且对"活跃"定义不敏感（稳健的阴性结果）。

**解读**：即便剔除了"两阶段都活跃"的细胞，只要保留同等数量的随机细胞，解码效果相近——提示跨任务解码并不依赖一组特异的"复用细胞"，而更可能是群体层面的分布式表征。

### 强活跃定义的敏感性（脚本 `CellReuse_StrongDefs.m`，0–1 s vs 基线）

| 活跃定义 | Learned/Transfer 强活跃交集（复用）占比 | 剔除复用是否显著差于随机 |
|---|---|---|
| `stim > 基线 + 3×基线SD` | **0%（无任何复用细胞）** | —（无可剔除） |
| `stim > 1`（z 单位） | **0%** | — |
| `stim > 2`（z 单位） | **0%** | — |
| 各阶段 `top 10%` | 2.4% | 否（pMI>0.95 0/9） |
| 各阶段 `top 20%` | 6.2% | 否（pMI>0.95 0/9） |

**关键发现**：在"强响应"定义（>基线+3SD 或绝对 z>1/2）下，**Learned 与 Transfer 之间不存在任何"两阶段都强活跃"的复用细胞**——强响应细胞是任务特异的，而非跨任务复用的。即便按 top 比例定义出少量复用细胞（2–6%），剔除它们对解码的影响也不显著超出随机。这与上述结论一致：**跨任务解码不依赖一组特异的复用细胞**。

### Fig1I 官方口径（1 s 处 > 基线 −3~0 s + 3×SD，中位数 Z-score，逐鼠）
脚本：`CellReuse_Fig1IDef.m`（与英文图 `Fig1I_ReusedCellsPie.m` 同一活跃判定；分母可选 Learned 活跃或同鼠总细胞）

- **复用细胞极少**：每鼠 0–31 个，占同鼠细胞 **0–4%**（平均约 1.5%），占 Learned 活跃细胞 0–38.5%（平均约 15%）。
- **解码剔除**（Choice/Cue cfg2）：因复用细胞占比太小，剔除后 MI 与 Stage2 倾向分离**几乎不变**，且均不显著（pMI>0.95 与 pS2>0.95 均 0/10）。
- **结论（与论文口径一致并更强）**：按官方定义，两阶段都强活跃的复用细胞数量极少，**不足以解释跨任务（Transfer）解码表现**；Transfer 的（微弱）解码主要由非复用细胞（>96%）的群体活动承载。

## 5. 可调整项 / 假设
- 活跃阈值（默认 > 0；可改为 >0.1 / 显著性 / top 比例）。
- 刺激响应窗口（当前 [0.3, 0.96] s）。
- Learned 是否单取 `Learned` phase（排除 Naive）。
- 是否同时分析 Cue 解码器。
- 反向对照：剔除"非复用细胞"作对照。
